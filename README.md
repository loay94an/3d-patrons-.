# 3D Patrons

**استوديو عربي لتصميم الأزياء وهندسة الباترونات ثنائية وثلاثية الأبعاد.**

يهدف المشروع إلى توفير مساحة عمل عربية (RTL) لتطوير الباترونات، ضبط المقاسات، استعراض النماذج ثلاثية الأبعاد، وتنظيم مراجع التفصيل والخياطة في مسار عمل واحد.

## ما يتضمنه المشروع

- واجهة عربية باتجاه RTL.
- أدوات إعداد وتعديل الباترونات، بما فيها لوحة رسم التنورة الأساسية.
- استوديو بارامتري وتخصيص ملفات القياسات.
- عارض ثلاثي الأبعاد ونماذج الملابس.
- كتالوج باترونات وموسوعة مراجع.
- اختيار الخامات وتصدير ملفات/صفحات الطباعة.
- إعدادات تطبيق ويب قابلة للتثبيت (PWA).

> المشروع قيد التطوير. وجود مكوّن أو شاشة في الشيفرة لا يعني أن كل وظائفها مكتملة أو مختبرة إنتاجياً.

## التشغيل محلياً

المتطلبات: Node.js حديث وnpm أو Bun.

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

أوامر المشروع المتاحة في `package.json`: `dev`, `build`, `preview`, `lint`, `test`.

## مكتبة المراجع

يوجد فهرس وصفي عام للمراجع المستخدمة في تخطيط المشروع:

- [فهرس المراجع بصيغة JSON](public/data/reference-catalog.json)
- [سياسة المكتبة وحالة الفهرسة](docs/reference-library.md)

**تنبيه حقوقي:** المستودع العام لا يتضمن ملفات الكتب الأصلية أو نصوص الصفحات أو OCR أو المقاطع المستخرجة. حالة الحقوق لبعض المراجع غير متحققة؛ لذلك يقتصر المنشور حالياً على بيانات وصفية وتصنيفية موجزة، ولا يعني ذلك أن الكتب متاحة للتوزيع.

## بنية العمل

- `src/`: تطبيق React وTypeScript ومكوّناته.
- `public/`: الملفات الثابتة وبيانات الكتالوج العامة.
- `docs/`: ملاحظات البحث والتصميم الهندسي.
