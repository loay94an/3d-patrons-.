# Original fashion reference library

## Purpose

This public catalog is a discovery and engineering index for the private reference collection. It is not a mirror of the source PDFs and does not reproduce their page artwork, written instructions, or pattern outlines.

## Catalog audit (2026-11-13)

The upstream Marlene Mukai enriched index contains 687 records in nine source folders:

| Source classification | Count | Public treatment |
|---|---:|---|
| needs_review | 542 | Design candidates; title-derived features only |
| tutorial_or_video | 91 | Technique/learning references, not garment models |
| pattern_or_patternmaking | 27 | Pattern-related references awaiting page inspection |
| tutorial_with_pattern | 27 | Tutorial references that may include a pattern |

All 687 records are marked as requiring page-level review. The source classifier reports `filename_only`; it does not establish that the PDF has been read or that its contents match the title.

## Original public presentation

- Arabic display labels and category taxonomy are newly authored for this application.
- Feature tags are conservative keyword inferences from source filenames. They are not verified garment specifications.
- Garment cards render original, schematic SVG concept illustrations from our own templates. They are not scans, traced images, reconstructions of a source page, or exact representations of a particular garment.
- Original source filenames are retained as private-reference metadata; source links point to the private repository and are not redistributed.
- No PDF pages, source photographs, page text, or extracted pattern outlines are included in this public catalog.

## Pattern engineering status

The 54 pattern-related records are *research candidates*, not editable patterns. A file is not marked as an editable pattern simply because its filename contains "pattern" or its catalog classifier says it may contain one.

Editable patterns must be authored independently from general drafting principles and the user's own measurements, then represented as CAD pieces with:
- explicit units and scale;
- grainline and fold information;
- cutting and stitch contours;
- seam allowances and notches;
- matched seam-length checks;
- measurement/ease assumptions;
- validation and sample-fit status.

Existing parametric drafting engines may be used to create original blocks (for example, the application's basic skirt and bodice/pants drafting functions). The pattern must pass geometric checks and be test-fitted before it is presented as production-ready. No source pattern page is to be traced or redrawn into a near-identical copy without permission or a license that allows it.

## Rights and provenance

Copyright commonly protects original expression such as photographs, illustrations, written instructions, and technical drawings, while not generally protecting ideas, procedures, methods, or facts as such. The exact boundary and other rights (including design rights, database rights, and contract terms) depend on jurisdiction and context.

For that reason, this project uses references to understand general construction concepts and measurement relationships, then creates independent explanations, illustrations, and parametric geometry. Access to a private PDF is not proof of permission to republish or adapt its expressive content. Rights status remains unresolved unless documented.
