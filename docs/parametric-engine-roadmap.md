# خارطة تطوير الاستوديو البارامتري

## الهدف
بناء منصة عربية احترافية لتصميم باترونات قابلة للتعديل وإعادة التوليد، مع فصل واضح بين قياسات الجسم، وراحة الملبس، وقواعد الرسم، وبدلات الخياطة، ومواصفات الإنتاج.

## طبقات النظام
1. **Anthropometry**: سجل قياسات بوحدات واضحة ونقاط استدلال وتعريفات قابلة للتتبع.
2. **Pattern DSL**: مواصفات بارامترية بلغة KTR، مع تثبيت إصدار اللغة وقدرات المترجم قبل التوليد.
3. **Drafting engine**: إنشاء القطع والمنحنيات والقيود الهندسية في محرك TypeScript الحالي.
4. **Fit & ease**: راحة مستقلة بحسب المنطقة والاتجاه والخامة، ثم مواءمتها مع خطوط الدرز.
5. **Validation**: إغلاق المحيطات، منع التقاطعات الذاتية، مطابقة أطوال الدرزات، علامات التطابق، النسيج، البدلات، والتحقق من المقياس.
6. **3D & production**: محاكاة لاحقة بعد اكتمال تحويل القطع، وتوليد حزمة إنتاج وتعليمات القص.

## منهجية المصادر
- Aldrich, *Metric Pattern Cutting*, 4th ed. (2004): بلوكات الجذع، الأكمام، الياقات، التنورة، البنطال، التعديلات، التدريج، وCAD.
- Aldrich, *Metric Pattern Cutting for Menswear*, 2nd ed. (1990): بلوكات الملابس الرجالية والكاجوال، القمصان، الأكمام، الياقات، البنطال، البدلات والتدريج.
- Armstrong, *Patternmaking for Fashion Design*, 5th ed. (2014): القياسات ونقاط الاستدلال، البنس، التحويلات، الملاءمة، إكمال الباترون.
- Kim & Park (2025), “Development of a parametric production jacket pattern for an automated pattern-making system”: فصل الباترون الأساسي عن سماحات الإنتاج وعناصر التصميم، والتحقق بمقارنة التدريج.
- Bartol et al. (2026), “EASE: Parametric Garment Design with Explicit and Local Ease Control”: راحة موضعية ومتباينة الاتجاهات كمتغير تصميم، مع قيود الدرز وتحسين الباترون والمحاكاة.
- KTR: مصدر اللغة الرسمي هو مستودع kutur-labs/ktr؛ لا تُستخدم الميزات غير المكتملة كأنها تعمل.

## بوابات الجودة
- لا تُعتمد صيغة قياس دون تعريف نقطة القياس ووحدته ومصدره.
- لا تُستخدم قيمة راحة واحدة لكل أنواع الملابس والأقمشة.
- لا يدمج بدل الخياطة مع خط الخياطة الأساسي في بيانات القطعة.
- لا يصدر ملف إنتاج قبل فحص طول الدرزات والتطابق والاتجاه والنسيج ومقياس الطباعة.
- لا تُوصف المحاكاة بأنها تحقق ملاءمة فعلية دون مقارنة مع عينة أو قياسات موثقة.

## مراحل التنفيذ
- المرحلة الحالية: مختبر مواصفات القياسات والراحة، وتوليد مسودة مصدر KTR للجزء المدعوم.
- التالية: محول KTR فعلي عبر WASM أو خدمة مستقلة بعد اختبارات التوافق، ثم نموذج بيانات موحد للقطع.
- بعدها: قواعد مستقلة للجذع والتنورة والبنطال والكم والجاكيت، ثم التدرج والملاءمة و3D وحزمة الإنتاج.
