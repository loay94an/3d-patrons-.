# مكتبة مراجع الباترون والرسم البارامتري

هذه المكتبة تنظّم الكتب والأبحاث المرفوعة من المستخدم وتحوّل المعرفة إلى مراجع قابلة للتتبع ونماذج هندسية أصلية قابلة للتطوير داخل 3D Patrons.

## محتويات الحزمة

- `src/lib/parametric-bodice-draft.ts`: مولّد TypeScript أصلي لرسم مسودة أساس صدري أمامي نصفية من القياسات بالسنتيمتر، مع سماحية راحة قابلة للتعديل. ينتج SVG بوحدات المليمتر.
- `basic-bodice-example.svg`: مثال توضيحي ثابت ناتج عن النموذج (صدر 92 سم، خصر 76 سم، طول 42 سم، راحة 8 سم).
- `references.md`: فهرس الكتب والأبحاث المستخرجة من الأرشيف، مع الروابط والبيانات الببليوغرافية وملاحظات الحقوق.

## تشغيل المولّد

```ts
import { generateFrontBodiceSvg } from "./parametric-bodice-draft";

const svg = generateFrontBodiceSvg({
  bustCm: 92,
  waistCm: 76,
  bodiceLengthCm: 42,
  shoulderCm: 12.5,
  easeCm: 8,
});
```

المدخلات بالسنتيمتر؛ المخرجات SVG بمقياس هندسي 1 وحدة = 1 مم. النموذج الحالي مسودة تعليمية أولية لقطعة أمامية نصفية، وليس باترون إنتاج معتمداً: لا يتضمن بعد بنسة الصدر/الخصر، تقويس حردة الإبط المعاير، مردّات، سماحات خياطة، أو اختبار ملاءمة على جسم حقيقي.

## سياسة الملفات والحقوق

لم تُرفع ملفات الكتب الكاملة إلى المستودع العام. تتضمن الحزمة ملفات كتب تجارية أو نسخاً مصدرها أرشيفات مشاركة، ولا يظهر في البيانات الوصفية ما يثبت حق إعادة توزيعها. لذلك نحتفظ بالعناوين والبيانات والروابط المرجعية فقط. يمكن إضافة ملفات PDF/EPUB لاحقاً عندما يثبت أنها ملك عام أو مرخصة صراحةً لإعادة التوزيع، أو عندما يقدم المستخدم إثبات حق النشر.

لا تُنسخ أوزان النماذج أو مجموعات البيانات من مصادر خارجية إلى هذا المستودع دون مراجعة الترخيص وشروط الاستخدام. تُسجل الروابط في الفهرس لتسهيل التكامل التقني لاحقاً.

## حدود الدقة

المثال البرمجي يثبت بنية توليد بارامتري قابلة للقياس والتعديل، ولا يدّعي استنساخ طريقة كتاب بعينه. يجب التحقق من القياسات، وإضافة قواعد البنسات والقصّات والراحة، ثم إجراء اختبارات ورقية/ملاءمة قبل استخدامه في الإنتاج.
