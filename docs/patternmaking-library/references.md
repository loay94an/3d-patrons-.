# فهرس الكتب والأبحاث – باترون وتصميم ملابس

المصادر أدناه مستخرجة من بيانات الملفات الوصفية للأرشيف المرفوع. الأسماء التي تبدأ بـ `annas-arch` هي أسماء ملفات أرشيفية وليست بالضرورة بيانات نشر موثوقة؛ يجب مطابقة الطبعة والناشر قبل الاقتباس العلمي.

## أبحاث التصميم البارامتري

1. **EASE: Parametric garment design with explicit and local ease control** — Kristijan Bartol وآخرون، arXiv:2606.29419v1 (14 صفحة). DOI: https://doi.org/10.48550/arXiv.2606.29419  
   رخصة PDF المضمنة: CC BY-NC-ND 4.0؛ لا تُعدّل النسخة ولا يُعاد توزيعها بما يخالف شروط الرخصة. هذا الفهرس لا يتضمن نسخة PDF.
2. **Development of a parametric production jacket pattern for an automated pattern-making system** — Narae Kim (2025)، *Fashion and Textiles*. DOI: https://doi.org/10.1186/s40691-025-00419-w  
   راجع صفحة الناشر وشروط الوصول وإعادة الاستخدام قبل تنزيل أو إعادة توزيع النص الكامل.

## كتب بناء الباترون

1. **Metric Pattern Cutting** — Winifred Aldrich. نسخة أرشيفية PDF، 200 صفحة.
2. **Metric Pattern Cutting** — Winifred Aldrich. نسخة PDF أخرى، 203 صفحات؛ يحتمل أنها طبعة/نسخة مكررة من المرجع السابق.
3. **Metric Pattern Cutting for Menswear: Including Unisex Casual Clothes and Computer Aided Design** — Winifred Aldrich. نسخة أرشيفية PDF، 152 صفحة.
4. **Metric Pattern Cutting for Menswear** — Winifred Aldrich. نسخة EPUB.
5. **Metric Pattern Cutting for Women's Wear, Fifth Edition** — Winifred Aldrich. نسخة PDF، 218 صفحة.
6. **Patternmaking for Fashion Design: Pearson New International Edition** — Helen Joseph-Armstrong. نسختان PDF متطابقتان ظاهرياً من حيث بيانات العنوان وعدد الصفحات (926 صفحة لكل نسخة).
7. **ملف PDF غير محدد العنوان** — 181 صفحة؛ بيانات العنوان/المؤلف غير موجودة في metadata، ويلزم فحص صفحة الغلاف يدوياً قبل اعتماده.
