# Fashion Model Library

مكتبة مرجعية موحّدة لملفات الباترونات والنماذج المستخدمة في 3D Patrons.

## البنية

```
assets/fashion-model-library/
├── overalls/
│   ├── catalog.json
│   └── source/          # ملفات PDF الأصلية بعد التحقق من الترخيص
├── tops/
├── trousers/
├── skirts/
├── other-patterns/
├── shared-assets/
└── README.md
```

## قواعد الإدخال

- الاحتفاظ بالاسم الأصلي وملف المصدر دون تعديل.
- تسجيل النوع والصيغة واللغة والمقاسات/القياسات إن توفرت.
- عدم اعتبار PDF قابلاً للدمج البرمجي تلقائياً؛ يحتاج تحليل صفحات/قطع الباترون واستخراج حدود القطع والخطوط والعلامات.
- عدم نشر ملفات لا نملك حق إعادة توزيعها. حالة الترخيص الحالية للدفعة المفهرسة: غير متحقق منها.
- لا تُسجّل الملفات كأصول مرفوعة إلا بعد وجودها فعلياً في Git.
- فصل الملاحظات المرئية على صورة الغلاف عن حقائق البناء المستخرجة من صفحات الباترون.

## تدقيق دفعة الأفرولات

تم فحص أرشيف `أفرولات.zip` المتاح في مكتبة المحادثة:

- 12 ملف PDF، بإجمالي 132 صفحة.
- صفحات A4، والملفات صور ممسوحة ضوئياً؛ لم يظهر نص قابل للاستخراج آلياً.
- تمت مراجعة صور الصفحة الأولى لتصنيف الشكل العام وإضافة وسوم بحث أولية.
- لم تُستخرج بعد حدود قطع الباترون أو القياسات أو بدلات الخياطة أو تعليمات التجميع.
- الأرشيف وملفات PDF غير ملتزمة إلى Git في هذه المرحلة.
- بصمة SHA-256 للأرشيف: `b8cabe1962145d2b1199dcc9c61f70595a5b9ae166c00d3e4ccd6ae69cc30ce6`.

لذلك يصف `overalls/catalog.json` الموديلات وصفاً أولياً قابلاً للبحث، ولا يمثل باترونات CAD جاهزة أو بيانات قياس إنتاجية. يجب مراجعة صفحات كل ملف بصرياً قبل تحويله إلى قطع رقمية.

## الحالة الحالية

تم تدقيق دفعة الأفرولات فقط. بقية الأرشيفات الخمسة التي ذُكرت سابقاً غير متاحة ضمن مكتبة الملفات الحالية، كما أن المستودع المرجعي الخاص `3d-patrons-library-private` غير ظاهر ضمن مستودعات GitHub التي يستطيع الاتصال الحالي الوصول إليها. لا تُسجّل أي ملفات أو موديلات من هذين المصدرين كأنها مستوردة حتى تصبح متاحة فعلياً.
